# Cools 无封装基板系统主板

## 面向 AI、HPC 与 CPO 的可转移 RDL 主板平台

> **平坦度借自临时载体。**  
> **精细布线先独立制造，再转移。**  
> **主板保持粗间距。**  
> **封装基板被移除。**

**Cools** 提出一种系统级先进封装架构：在独立的平坦临时载体上制造并测试高密度重布线层（Redistribution Layer，RDL），随后将其直接转移到粗间距系统主板或高导热冷却骨架上。

该平台的目标不是把整块主板制造成大面积细线路印刷电路板，而是仅在真正需要高密度互连的区域布置精细 RDL，同时保留主板的大面积制造能力、机械支撑功能及粗间距布线能力。

## 1. 系统结构的转变

### 传统先进封装

```text
GPU / ASIC / HBM / Chiplet
            ↓
         中介层
            ↓
       有机封装基板
            ↓
          主板
```

### 细线路主板方案

```text
GPU / ASIC / HBM / Chiplet
            ↓
         中介层
            ↓
 大面积细线路系统 PCB
```

该方案把封装基板承担的重布线任务转移给大面积、粗糙且易翘曲的系统板，因此会产生对准、平坦度和良率瓶颈。

### Cools 架构

```text
GPU / ASIC / HBM / Chiplet
            ↓
可转移高密度 RDL 覆盖层
            ↓
粗间距系统主板或冷却骨架
```

可转移 RDL 负责细间距连接、扇出、高速信号、电源与接地分配以及局部芯片间连接。下方系统板保持粗间距，不必制造成大面积细线路 PCB。

## 2. 一个平台，多种尺度

### 局部 RDL 补丁

仅在 GPU–HBM、Chiplet 互连、交换 ASIC、光引擎等需要高密度连接的区域设置小型精细布线补丁。

- 精细布线仅存在于必要区域
- 可移除有机封装基板
- 主板保持粗间距
- 补丁可独立制造、测试和更换

### 多区域扇出覆盖层

单一可转移结构可划分为多个平面转换区域。逻辑芯片、HBM、电源管理器件及光子器件的不同端子间距，可分别以不同转换比连接至主板间距。

### 板级 RDL 表皮

将大面积或近乎整面的高密度 RDL 表皮转移到粗间距主板上，在不直接细化主板的情况下形成重布线一体化系统板。

### 已知良品 Tile 网络

将大面积 RDL 拆分为多个独立制造、独立测试的已知良品 Tile，再通过 Tile 间桥接 RDL 形成连续或功能连续的布线网络。出现缺陷时，仅需更换对应 Tile，而不是报废整块大面积 RDL。

## 4. 制造路径

该系统架构不依赖单一金属化方法。

### 路径 A — 现有半加成工艺

在平坦临时载体上采用 PCB 与封装基板企业已拥有的半加成工艺（Semi-Additive Process，SAP）。

```text
平坦载体
→ 种子层
→ 电镀光刻胶图形
→ 图形电镀
→ 种子层闪蚀
→ 多层 Build-up
→ 检测
→ 载体分离
→ 直接转移至系统板
```

关键变化不是必须更换工厂设备，而是改变被加工表面。精细图形在平坦载体上形成，而不是直接在粗糙、翘曲的主板上形成。

### 路径 B — 超薄铜箔载体，无真空种子层

使用附着在载体上的超薄铜箔作为公共电镀供电层，可在载体侧不形成物理气相沉积（Physical Vapor Deposition，PVD）种子层的情况下完成图形电镀。

载体分离后，对超薄铜箔进行全面或选择性蚀刻，可形成埋入式底部端子及可检测的凹陷结构。

### 路径 C — 湿式界面导向金属化

利用聚乙烯亚胺（Polyethyleneimine，PEI）、乙氧基化聚乙烯亚胺（Ethoxylated Polyethyleneimine，PEIE）等含胺界面层捕获催化金属，并形成化学镀阻挡层与种子层。

粘附、成核、金属离子捕获、扩散阻挡和低电阻铜布线可由不同功能层分别承担，适用于玻璃、陶瓷、绝缘膜及部分高深宽比结构。

## 5. 与高导热冷却骨架集成

可转移 RDL 不仅可用于有机主板，也可与反应结合碳化硅（Reaction-Bonded Silicon Carbide，RBSC）、碳化硅（Silicon Carbide，SiC）及金属–陶瓷复合材料等高导热、高刚度结构结合。

### 表面转换

```text
孔隙封闭
→ 绝缘层过量沉积
→ 研磨 / 抛光 / CMP
→ 平坦绝缘基准面
→ 直接形成或转移 RDL
```

粗糙、多孔、导电或半导电表面可被转换为适合精细布线的平坦绝缘表面。

### 冷却通道与垂直连接

骨架内部或底部可形成冷却通道。穿过导电骨架的电极通过绝缘衬层与骨架本体电隔离，并与冷却液保持气密隔离。

在选定结构中，导电骨架还可用作接地基准面或电磁屏蔽层。

### 最终系统功能

- 精细及粗间距电路布线
- 机械支撑
- 垂直电连接
- 热扩散与直接冷却
- 接地与电磁屏蔽

因此，主板可从被动布线板转变为集成布线、支撑、散热与冷却的系统骨架。

## 6. 良率、可靠性与权利识别

### 已知良品转移

精细布线体或各个 Tile 可在与最终系统板接合之前进行开路、短路、电阻、绝缘、阻抗、连续性及光学缺陷测试。

### Tile 与补丁更换

利用局部释放区、可返修接合线和桥接修复布线，可仅移除并更换缺陷 Tile 或补丁。

### 热机械应力缓冲

移除有机封装基板时，其传统应力缓冲功能也会消失。平台可采用：

- 低模量缓冲层
- 柔顺导电柱
- 弯曲形重布线互连
- 外周大型或虚设接点
- 加强框架与柔顺接合结构组合

### 可检测结构指纹

可转移结构可通过以下可测量特征与主板直接 Build-up 结构区分：

- 由载体形成的平坦基准面
- 相反方向的 Via 锥度或镜像 Build-up 顺序
- 半加成种子层蚀刻痕迹
- 释放层残留
- 切割侧壁和接合线
- 精细覆盖层与粗间距主板之间的间距域分离

## 7. 电光扩展

可在单一可转移覆盖层内同时集成电重布线层和光波导层。

```text
电精细 RDL
+ 光波导
+ 电连接垫与光耦合器
+ 光子集成电路接口
= 可转移电光一体化覆盖层
```

该结构可采用聚合物、玻璃、氮化硅或二氧化硅光波导，并结合光栅耦合器、边缘耦合器、反射镜或光学 Via，从而扩展至共封装光学（Co-Packaged Optics，CPO）及板级光输入/输出。

## 8. 系统级比较

| 项目 | 传统封装堆栈 | 细线路主板方案 | Cools 可转移 RDL 平台 |
|---|---|---|---|
| 有机封装基板 | 必需 | 缩减或移除 | 在目标架构中移除 |
| 精细布线形成位置 | 中介层与封装基板 | 大面积系统 PCB | 独立平坦载体 |
| 主板间距 | 粗间距 | 必须细化 | 保持粗间距 |
| 大面积良率单元 | 封装/中介层 | 整块细线路主板 | 补丁、整片或已知良品 Tile |
| 返修 | 有限 | 板级返修困难 | 补丁与 Tile 更换结构 |
| 热集成 | 追加冷却部件 | 受 PCB 热性能限制 | 可与高导热冷却骨架集成 |
| 电光集成 | 分离结构 | 依赖特定主板 | 可通过单一可转移覆盖层集成 |
